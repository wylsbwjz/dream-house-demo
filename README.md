# Dream House · 方案协同 Agent Demo

**让 AI 推进设计，让用户掌握变更。**

这一版把「一次局部替换」做成完整可操作的桌面工作台：从**我的家主页**进入已确认的餐办共用 C v3，选中餐桌，用模板或自然语言说明条件，核对 AI 整理出的可修改摘要，观察任务阶段，比较候选，预览后再应用，并在清单、对比与版本历史中继续核对和撤销。**灵感**页把收藏案例变成可执行的修改要求，**决策笔记**把对比结论与方案版本互相引用。

> 当前版本是**本地规则演示**：意图解析、目录筛选、计价与几何校验都在浏览器内完成，不调用真实模型，不联网搜价。页面上明确标注运行模式，没有伪装成实时模型推理。

## 页面结构

- **我的家**：项目总览主页——空间、已知费用、待确认项、房间、最近活动与灵感/笔记入口，一键继续上次任务。
- **方案画布 / 空间编辑 / 方案对比 / 商品与预算**：四个工作视图，围绕同一方案版本联动。
- **方案画布（无限延伸）**：风格与配色、材质与面料、灵感参考图、家具样式、决策笔记都可以铺在画布上并连线到当前方案；这些素材只展示、可定位，不需要点击打开。右上缩略图是「方案总览」，点哪里就定位到哪里。
- **灵感**：发现 / 收藏 / 我的笔记；案例详情可「提取设计要素」并进入同一意图链路。
- **选物**：任务驱动的替代选品池，展示符合项、排除项与尺寸容差分析。

## 四个重点

1. **意图识别模板**：从当前选择继承对象与保留条件；提供「寻找平替」任务模板、三条情境示例和自由输入。示例只填入、不执行；模板不是表单，而是一句可以改写的话。
2. **执行过程渐进式披露**：L0 范围与版本常驻，L1 四个阶段由真实计算更新，L2 关键结果就地保留，L3 依据、工具与排除理由按需展开。失败、取消与过期都有真实状态。
3. **自由画布**：可无限延伸的平移缩放工作板，承载项目依据、A/B 参考方向、C 的版本链、候选批注，以及风格、配色、材质、参考图、家具样式与决策笔记等素材节点，并连线到当前方案。默认聚焦主簇，缩略图「方案总览」可点击定位；它不是图片墙，也不是节点编辑器；精度调整发生在空间编辑。
4. **可控的局部修改**：只替换 `table-01`，预览不改正式金额，应用生成 C v4，撤销生成 C v5；移动餐桌会让旧候选过期，重新校验保留新位置。
5. **灵感与决策进入方案**：案例「提取设计要素」生成一句可核对的要求，进入同一摘要链路；对比结论可保存为决策笔记，与当时的版本互相引用，随时回到那一次对比。

## 体验主线（约 4 分钟）

1. 打开「我的家」主页，查看空间、费用与待确认项，点击「进入客厅方案」。
2. 选择「控制预算」示例，或直接改写输入；点击「整理修改要求」。
3. 核对摘要：必须满足（长/宽/单价）、保留条件、可妥协项分组呈现；待确认项需要回答才能继续。示例不会静默解除保留条件。
4. 确认后观察四个阶段：读取方案 → 核对约束 → 筛选目录 → 计算影响。目录内找到 T150 Lite（−¥300）与 T140（−¥500）；T120 与 R130 因低于确认下限被排除。
5. 切换候选：桌面与占地实际变化，正式金额仍为 ¥8,080；底部单独显示候选预计 ¥7,580。可进入「选物池」查看筛选、被排除项与尺寸容差分析。
6. 点击「应用并生成 C v4」：生成 C v4，空间、底部费用、清单、对比与版本历史同步为 T140 / ¥7,580。
7. 在「商品与预算」中定位餐桌；在「方案对比」中查看 A/B/C 同角度与 C v3 → v4 的几何对照。
8. 点击「撤销这次替换」：生成 C v5，恢复 T150 与 ¥8,080；应用后对位置的手动调整仍然保留。

### 异常保护（B 段，约 45–60 秒）

在候选就绪或预览状态，用方向键或拖拽移动餐桌：

- 候选立即标记「已过期」，应用按钮消失；
- 顶部与右侧说明具体变化，保留候选、输入与工作副本；
- 点击「按最新布局重新检查」，在新位置重新筛选并恢复预览；
- 也可以「放弃提案」，回到摘要重新确认。

### 两条新增链路（灵感 / 决策笔记）

**链路 A · 灵感进入方案：**灵感「发现」打开案例 → 勾选「提取设计要素」→ 生成一句可核对的要求 → 进入同一套摘要确认、候选预览与应用流程。收藏可撤销，收藏进入「收藏」页签。

**链路 B · 决策笔记与版本回溯：**方案对比点击「保存为决策笔记」→ 编辑器自动附带对比版本、餐桌与费用差异，可勾选选择理由 → 保存后在灵感「我的笔记」中找回，并可「回到当时的对比」。

「灵感与材质」色板已迁移为「界面视觉规范」，入口在演示设置中。

## 视觉

- 美拉德色系：暖白底、深棕主行动、焦糖分层；青绿只用于当前对象与占地，蓝色只用于候选未应用，琥珀只用于过期，砖红只用于冲突。
- 每款餐桌有独立配色与腿型（方腿 / 锥形腿 / X 型交叉腿 / 板式腿），商品图、空间场景、平面图与选物卡片共用同一份样式数据，替换前后一眼可见。
- 1440×1000 为优先演示尺寸，1280×900 可完成核心操作；空间支持 3D 等轴测、平面 2D 与实拍参考三种观察方式。
- 自由画布支持拖拽平移、滚轮缩放、双击适配与缩略图定位；空间支持拖拽、方向键 10cm 移动、90° 旋转与数值输入。
- 键盘：`⌘/Ctrl + K` 搜索与跳转；方向键移动餐桌；`R` 旋转；`Esc` 退出预览或关闭浮层。

## 运行

依赖已安装。需要 Node.js 与 pnpm。

```text
# 开发模式（Vite + 本机服务），默认 http://127.0.0.1:4317
pnpm dev

# 构建静态产物 + 托管 Worker
pnpm build

# 生产预览（构建后）
node server/local.mjs --production
```

也可以双击 `启动Demo.cmd`：它会在本机启动生产预览并打开浏览器；`停止Demo.cmd` 结束这个后台进程。构建产物位于 `dist/`，服务端不包含模型密钥。

端到端验收（先让 Demo 在 `http://127.0.0.1:4317` 运行）：

```text
pnpm test:browser
```

如果预览在其他端口，设置 `DEMO_URL`，例如 PowerShell：

```text
$env:DEMO_URL='http://127.0.0.1:4320'; pnpm test:browser
```

> 页面数据保存在当前浏览器 `localStorage`（键：`dream-house-agent-v2`）。演示前可点击「演示设置 → 重置」，或使用演示指引中的重置按钮回到 C v3。

## 与真实模型的边界

- 本版没有接入真实模型或网络检索。`server/agent.mjs` 保留了受限工具适配器，但当前界面不调用它，也没有「自动降级」或「假流式推理」。
- 商品、价格、材质、空间与安装费用均为虚构示例；安装费始终是待确认项，差额不被称为可用余额。
- 几何检查只覆盖房间边界与部分家具遮挡，不代表通行、结构或施工合规。
- 这是单用户、单标签页的概念演示；多人协作、真实扫描、AR、商城与支付不在范围内。

## 已实际验证

`tests/browser-v2.cjs` 在 Edge 无头模式下跑通并通过（20 项）：

- 主页落地并可进入客厅方案；
- 画布素材簇（配色/材质/参考图/家具/笔记/聚焦）渲染完整，缩略图总览点击可定位；
- 示例只填入、不改方案；
- 两个符合候选；预览改几何但不改正式金额；
- 清单保留正式行并显示候选行；待确认筛选只显示未知费用；
- 应用原子写入 C v4；对比固定 v3 / v4，结论条一句话说明差异；
- 移动后撤销保留新位置；
- 移动候选过期、应用被阻断、重新校验保留位置；
- 刷新恢复保存状态；
- 无结果时如实说明并提供组合放宽；
- 对比结论保存为决策笔记，可从笔记回到当时的对比；
- 灵感收藏进入收藏页签；提取设计要素进入同一意图摘要链路；
- 1280 宽度无横向溢出；1440/1280 关键文字字号提升；
- 控制台无错误。

另有截图与录屏素材位于 `qa/v2/`。这些都是工程自检，不代表真实用户研究或效率提升数据。
